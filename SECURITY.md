# Security policy

## Reporting a problem

Please report security issues privately, not in a public issue:
use **[Report a vulnerability](https://github.com/shreyasudupi/HackerTube-TV/security/advisories/new)** on this repo's Security tab.
You'll get a reply within a few days.

Helpful details: the app version (Settings > About), your device, and steps to reproduce.

## Scope

- **This repo:** the HackerTube overlay and patch, the build/release workflows, and the update channel.
- **Upstream SmartTube:** problems in SmartTube itself belong with [SmartTube](https://github.com/yuliskov/SmartTube). If one affects HackerTube TV too, tell us as well and we'll ship the fix.
- **hackertube.org:** the website and its API are run separately by its author.

## Verifying a download

Every release APK has a build attestation and checksums. See the Security section of the [README](README.md#security).
